# Step 6 — Khôi phục UI / Design từ code

Legacy thường không có Figma, nên tái dựng UI bằng chữ từ code:
- Code phía admin/back-office → màn hình admin, field, trạng thái, message validate.
- Code phía người dùng cuối → cái họ thấy và tương tác (hover/selected/disabled/loading/empty).

Viết vào `spec.md` → `## UI / Design` dạng mô tả (màn hình, trạng thái, tương tác), mỗi phần neo về component (neo để
dành cho bảng traceability của `tech.md`).

Áp nguyên tắc **concrete** (SKILL.md #2) ở đây luôn: nếu code render **N màn hình/view theo điều kiện**, liệt kê **đủ N
màn** + **đúng điều kiện nào ra màn nào**, đừng gộp "một vài màn hình tuỳ trạng thái". Mỗi trạng thái (loading/empty/
error/disabled) thấy trong code → một dòng.

Để `meta.yml.design`/`ui` là `null` trừ khi thật sự có file design. Ở hand-off, ngỏ ý sinh một `ui.html` tái dựng nếu
người dùng muốn bản trực quan.
